# TECRID → VLE evidence handoff v1

VLE remains a separate application. No VLE source, accounts or records are changed by this package. Emit a handoff only after TECRID issuance succeeds; a reservation, private intake or sandbox identifier is not issued evidence.

| Field | Source / rule |
|---|---|
| `contractVersion` | `tecrid-vle/1` |
| `tecrid` | Actual returned issued identifier; never generated by VLE |
| `resolverUrl` | `https://tecrid.com/records/` plus URL-encoded identifier |
| `statusUrl` | `https://tecrid.com/api/v1/credentials/` plus URL-encoded identifier |
| `versionsUrl` | `statusUrl + /versions`; redacted for controlled findings |
| `issuer.code`, `issuer.name`, `issuer.status` | Current resolver response |
| `reportNumber`, `orderNumber`, `sourceSha256`, `sourceFilename` | Signed sourceDocument; compare to exact original PDF |
| `sampleDescription`, `lotNumber` | Signed subject; preserve original text and scope |
| `testedAt`, `releasedAt`, `issuedAt` | Separate dates, never backdate credential issuance |
| `version`, `status`, `fingerprint`, `checkedAt` | Re-fetch at every meaningful reliance decision; no permanent "verified" flag |
| `visibility`, `resultsAccess` | Honor controlled findings; public status is not authorization to retrieve findings |
| `vleSamplingId`, `vleCustodyId` | `null` for historical Kasandrinos reports; never invented |
| `sharingAuthority` | Brand-controlled recipient grant/share-code reference when applicable; no onward-sharing assumption |

## Verification

1. Resolve the identifier over HTTPS with no cached status. Require `status: issued` and a currently verified issuer; 202 means reservation only, 404 means no public credential. Revoked records must stop reliance, not disappear from history.
2. For public findings, verify Ed25519 over the exact UTF-8 `integrity.issuerProof.signedPayload`, its SHA-256, and the current version's canonical payload fingerprint. The connector `verify` command performs these checks. Obtain the reviewed public key through the trusted registry/issuer relationship; a self-asserted key alone does not establish lab identity.
3. Match report number, lot/sample, dates, source hash and units/qualifiers against the intended report. ND/NR are not zero. Cryptographic authenticity does not prove representative sampling, regulatory compliance or safety.
4. For controlled findings, use the existing authorized routing/share-code flow. A recipient gets only the disclosure it is entitled to. Redacted public data is insufficient for independently verifying withheld analytical payloads.
5. Corrections append signed versions; revocation appends a signed status change. Poll status on use and reconcile version/fingerprint changes. No webhook subscription is implemented by this package.
6. Keep the original PDF private unless separately authorized. The public resolver does not expose the file. Kasandrinos retains access through its submitting workspace, or the existing controller routing receipt for newly routed reports.

A public legacy report requires explicit laboratory confirmation of public disclosure authority. If that authority is absent, keep the intake private. Do not manufacture a controlled legacy credential by changing a signed payload's visibility.
